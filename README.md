# Customer-Churn-Analytics
Customer churn analysis using Python, Pandas, NumPy, and Matplotlib.
##  Project Overview

This project explores customer churn in a telecommunications company using Python.

##  Objectives
- Analyze the overall customer churn rate.
- Identify customer groups with higher observed churn rates.
- Explore relationships between churn, contract type, tenure, payment method, and subscribed services.
- Provide data-driven recommendations for customer retention.

##  Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

##  Key Findings
- Overall churn rate: approximately 26.6%.
- Month-to-month customers show higher churn than longer-contract customers.
- Customers with shorter tenure have higher observed churn rates.
- Electronic check users show a higher observed churn rate than other payment groups.

## Project Files
- `Customer_Churn_Analytics (2).ipynb` — Jupyter Notebook containing the analysis.
- `date/WA_Fn-UseC_-Telco-Customer-Churn.csv` — Dataset used for analysis.

##  Limitations
This project uses exploratory data analysis. The findings show associations, not proof of causation, and no predictive model is included.
